# Electrical & Solar Load Calculator ⚡

A simple Python CLI tool to calculate total connected electrical load, daily energy consumption (in kWh/Units), and estimated monthly electricity bills.

## Features
- Add multiple home or industrial appliances.
- Calculates total load in Watts and Kilowatts (kW).
- Estimates daily unit consumption and monthly electricity cost.

## How to Run
```bash
python calculator.py
